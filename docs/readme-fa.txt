پرداخت با قدرت خرید کربن: پول نقد، دارایی (طلا و نقره)، اعتبار و تسهیلات.

== Description ==

با افزونه پرداخت کربن، مشتریان فروشگاه ووکامرسی شما می‌توانند با پول نقد، طلا و نقره یا اعتبار کربن خرید کنند و شما آنی تسویه می‌گیرید.

* پشتیبانی از تسویه حساب کلاسیک و بلوکی ووکامرس
* سازگار با HPOS
* انتقال خودکار تنظیمات و سفارش‌ها از افزونه جی‌اس‌ام پی

پیش‌نیازها: ووکامرس ۸٫۹ یا بالاتر (آزموده‌شده تا ۱۱٫۲)، واحد پول فروشگاه ریال، تومان، هزار ریال یا هزار تومان، و یک درگاه فعال در پنل پذیرندگی کربن.

== Installation ==

1. افزونه را بارگذاری و فعال کنید.
2. به «ووکامرس › پیکربندی › پرداخت‌ها» بروید و «کربن — پرداخت با قدرت خرید» را مدیریت کنید.
3. کد پذیرنده را وارد کنید.
4. آدرس بازگشت نمایش‌داده‌شده و IP خروجی سرور خود را در پنل پذیرندگی کربن ثبت کنید.
5. «بررسی اتصال» را بزنید تا مطمئن شوید کربن کد پذیرنده و IP را می‌پذیرد.

== Frequently Asked Questions ==

= چرا درگاه کربن در صفحه پرداخت نمایش داده نمی‌شود؟ =

درگاه فقط وقتی نمایش داده می‌شود که فعال باشد، کد پذیرنده وارد شده باشد و واحد پول فروشگاه ریال، تومان، هزار ریال یا هزار تومان باشد.

= مشتری پیام «ارتباط با کربن برقرار نشد» می‌بیند. =

معمولاً کد پذیرنده اشتباه است یا IP سرور شما در پنل کربن ثبت نشده است. جزئیات خطا در «ووکامرس › وضعیت › گزارش‌ها» با منبع carbon-pay ثبت می‌شود.

= چطور قبل از راه‌اندازی، پرداخت را آزمایش کنم؟ =

یک سفارش کوچک با کربن ثبت و پرداخت کنید.

= آیا می‌توانم سفارش کربن را از ووکامرس برگشت بزنم؟ =

خیر. برگشت وجه مستقیماً با کربن انجام می‌شود. ووکامرس همچنان می‌تواند بازپرداخت دستی را روی سفارش ثبت کند.

= از افزونه جی‌اس‌ام پی استفاده می‌کردم. =

افزونه کربن را فعال و سپس جی‌اس‌ام پی را غیرفعال کنید. تنظیمات و سفارش‌ها به‌صورت خودکار منتقل می‌شوند و پرداخت‌های در جریان هم تکمیل می‌شوند.
